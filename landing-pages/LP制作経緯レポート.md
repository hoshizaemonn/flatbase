# FLAT BASE PRイベントLP — 制作経緯レポート

## プロジェクト概要

株式会社フラットベース（FLAT BASE inc.）のPRイベント制作サービスに特化したランディングページ（LP）を制作するプロジェクト。既存コーポレートサイト（flat-base.jp）からリンクさせる前提で、トーン&マナーの統一を維持しながら、競合分析・参考サイト調査を経て最終デザインに落とし込んだ。

---

## Phase 1：企業調査・リサーチ

### 目的

LP制作に先立ち、フラットベースの事業内容・メンバーの経歴・仕事の具体像を深掘りし、コンテンツの裏付けとなる情報を収集する。

### 調査対象

- **株式会社フラットベース 公式サイト**（flat-base.jp）
- **代表取締役 金子 大羅（たいら）氏の経歴** — ベクトルグループ（株）プラチナムに約12年間在籍、執行役員として約60名のマネジメントを経験
- **メンバー4名の専門領域と職歴**
  - 川上 雄三（取締役 / イベント制作統括）— 舞台監督として多数のPRイベント・記者会見を担当
  - 小川 匠（執行役員 / 動画PR統括）— NewsTV出身、200案件以上・400本以上の動画PR実績
  - 鵜川 くるみ（コミュニケーションプランナー）— ビジネスメディアを得意領域とした統合コミュニケーション設計
- **ベクトルグループ / プラチナムの事業内容** — アジアNo.1・世界6位のPRエージェンシーで培った知見
- **D2Cブランド「VALVE」** — アウトドア用品の自社ブランド展開

### 成果物

`flatbase_調査レポート.md`（339行の包括的リサーチレポート）を作成。メンバーの仕事内容を「情景が浮かぶレベル」で記述し、LP制作時のコンテンツ原案として活用。

## Phase 2：LP構成案の分析とv1制作

### クライアントからの提供物

先方から`LP構成案.pptx`（2スライド）を受領。

**スライド1：PRイベント（プレス向け）とは**
- PRイベントの概要説明
- PRイベントを構成する8つの要素（目的・KPI設定、会場選定、予算管理、出演者選定、メディア選定、演出・造作、実施計画書・進行台本、当日の運営・進行）
- 参考URL 4件（電通PRC、Creative Factory、KMCグループ）
- デザインイメージは既存サイトに合わせたい旨の記載

**スライド2：なぜフラットベースが業界唯一の制作会社なのか**
- 3つの強み（年間平均60件の実績、最大手PR会社出身12年の経験、コストパフォーマンス）
- CTA（お問い合わせ誘導）

### 既存サイトのデザイントークン抽出

flat-base.jpのCSSをブラウザ経由で解析し、以下のデザインシステムを抽出した。

| 要素 | 値 |
|------|-----|
| フォント | Montserrat（英語）+ Noto Sans JP（日本語） |
| メインカラー | #191919（ブラック）、#d7d7d7（グレーライト）、#f9f9f9（オフホワイト） |
| サブカラー | #656363（ダークグレー）、#a9a9a9（ミッドグレー） |
| セクション余白 | 上下 150px |
| レタースペース | 英語 4.8px / 3px、日本語 0.08em |
| セクション構成 | ダーク/ライト交互パターン |

LP独自のアクセントカラーとして **#c8a86e（ゴールド）** を追加。既存サイトのモノトーンとの差別化とプレミアム感の演出を意図。

### 参考サイト調査

PPTX内に記載されていた4つの参考URLを調査。

| サイト | 特徴・学び |
|--------|-----------|
| 電通PRC（dentsuprc.co.jp） | 大手の信頼感を活かした構成。実績数値の大きな訴求 |
| 電通PRC LP（prx.dentsuprc.co.jp） | フルスクリーン写真と余白を活かしたプレミアムデザイン |
| Creative Factory（creativefactory-co.jp） | サービスフローの明確な図解。顧客導線の参考 |
| KMCグループ（kmcpr.co.jp） | 競合として最重要。CVR最適化されたLP構成パターン |

### v1 LP構成

以下のセクション構成でHTML/CSSの初版を作成。

1. Hero（キービジュアル + 実績数値）
2. About（PRイベントとは）
3. Process（8つの構成要素）
4. CTA（中間コンバージョン）
5. Why FLAT BASE（3つの強み）
6. Team（メンバー紹介）
7. Company（会社概要）
8. Contact（問い合わせフォーム）
9. Footer

### v1のコードレビュー結果

サブエージェントによるレビューで8.5/10のスコア。指摘に基づき以下を修正。

- OGメタタグの追加
- チームアバターの`border-radius: 50%`追加
- フォームフィールドのrequired属性と*マーク追加
- 電話番号フィールドの追加
- フッターロゴのコントラスト改善

## Phase 3：競合分析に基づくv2フルリビルド

### きっかけ

クライアントとの会議で、KMCグループ（https://www.kmcpr.co.jp/lp/pr_009_prevent/）がフラットベースと「全く同じような内容」をしている競合であることが判明。このLPを徹底分析し、参考サイトの知見も統合した上で、フラットベースのトンマナを活かしてLPを再構築する指示を受けた。

### KMC競合LP分析

KMCのLPから抽出した構成パターン。

| セクション | KMCの手法 | フラットベースへの応用 |
|-----------|----------|---------------------|
| ファーストビュー | 「業界唯一100%」+デュアルCTA | 統計数値の大きな訴求 + 2つのCTAボタン |
| 顧客満足度 | ソーシャルプルーフ | 実績数値で信頼を醸成 |
| 5つの特徴 | ナンバリング + タグ + 説明 | Processセクションでナンバリングを活用 |
| 選ばれる3つの理由 | メディア経験者/ISO/広告賞 | Why FLAT BASEセクションでカード3枚構成 |
| 9つの事例 | ロゴ + 写真 + 1行説明 | （写真素材未提供のため保留） |
| Flow | Before/After注文の2段階 | 2カラムでBefore Order / After Orderを図解 |
| FAQ | 4問のアコーディオン | 4問のアコーディオン（JS実装） |
| Final CTA | 最後の行動喚起 | CTA Bandを戦略的に複数配置 |

### v2で追加した新セクション

**1. Worries（悩み共感）セクション**
- KMCスタイルのペインポイント訴求
- 2×2グリッドで4つの悩みを提示
- 「PR視点が弱い」「手戻りが多い」「費用が膨らむ」「安心して任せられない」

**2. Flow（ご依頼の流れ）セクション**
- Before Order（ご発注前）3ステップ + After Order（ご発注後）5ステップ
- 2カラムレイアウトで視覚的に整理

**3. FAQ（よくあるご質問）セクション**
- 4問のアコーディオンUI
- JavaScriptによるクリック開閉アニメーション

**4. デュアルCTAバンド**
- Processセクション後とTeamセクション後の2箇所に配置
- ゴールドボタン（プライマリ）+ アウトラインボタン（セカンダリ）

### v2でのデザイン改善

- **ヘッダー**：固定ナビゲーション + スクロール時の背景変化（`backdrop-filter: blur`）
- **Hero**：プライマリ（ゴールド）+ セカンダリ（アウトライン）のデュアルCTA
- **Processセクション**：06〜08に`.highlight`クラスを追加し、フラットベースが担当する領域をゴールド背景で視覚的に強調
- **Team**：白背景のカードフォーマットにホバーリフトエフェクト追加
- **全体**：Intersection Observer APIによるスクロールフェードインアニメーション

## Phase 4：QA・品質改善

### コードレビュー結果

サブエージェントによる包括的QAレビューを実施。36項目の検証を行い、Critical 2件・Medium 11件・Low 23件の指摘。

### 修正した主要項目

| 優先度 | 項目 | 修正内容 |
|--------|------|---------|
| Critical | フォームname属性 | 全5入力フィールドにname属性を追加 |
| Critical | フォーム送信処理 | JS処理とサクセスメッセージUIを追加 |
| Medium | 見出し階層 | `<div>`を`<h2>`セマンティックタグに変更（7箇所） |
| Medium | inline onclick | 全4箇所をJS event delegationに移行 |
| Medium | OG/Twitter Card | og:urlとTwitter Cardメタタグを追加 |
| Medium | アクセシビリティ | `:focus-visible`スタイル、aria属性、label-for紐付けを追加 |
| Medium | prefers-reduced-motion | アニメーション無効化メディアクエリを追加 |
| Low | セマンティクス | `<main>`ラッパー追加、`<br>`タグをCSSマージンに置換 |
| Low | パフォーマンス | IntersectionObserverの`unobserve`でメモリリーク防止 |
